# Milestone 2 implementation notes

One file per phase, written in that phase's pull request from [template.md](template.md). The notes say what was built, how to try it, what hardware it was tried on, how it was designed, where it departs from the [phase spec](../phases.md), and what's left to do. The reasons behind significant decisions go in [ADRs](../../adr/README.md).

## Status

A phase's notes are marked *In review* in its own pull request. The next phase's pull request marks them, and the phase's row in the [plan's overview](../implementation-plan.md#7-phase-overview), *Done*, since a merged pull request can't be edited. A driver phase is *Done* only after the owner has run its "How to try it" on the device.
